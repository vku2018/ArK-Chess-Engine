# Code of Conduct

Ark contributors are expected to keep technical discussion direct, respectful, and focused on the work.

## Standards

- Treat other contributors professionally.
- Critique code, tests, measurements, and claims rather than people.
- Keep issues and pull requests on topic.
- Provide evidence for performance, correctness, and strength claims.
- Avoid harassment, insults, discriminatory language, and private information disclosure.

## Enforcement

Maintainers may edit or remove comments, lock discussions, close issues, or restrict participation when conduct damages the project. Reports can be raised through GitHub issue moderation or repository maintainer contact channels.
