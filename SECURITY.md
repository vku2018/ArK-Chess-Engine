# Security Policy

## Supported Versions

Ark is in early development. Security fixes target the current `master` branch.

## Reporting a Vulnerability

Open a private vulnerability report through GitHub Security Advisories when available. If that is not available, open an issue with minimal reproduction details and avoid posting secrets, credentials, or private datasets.

## Secrets and Artifacts

Do not commit credentials, API keys, model checkpoints, replay datasets, logs, or local run outputs. Use ignored local paths for generated artifacts.
